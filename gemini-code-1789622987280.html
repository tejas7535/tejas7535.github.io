01 / Background & Architecture

Problem & Architectural Solution

Direct comparison between legacy enterprise challenges and the automated design token approach.

The Problem Legacy Overhead

UI Inconsistency & Visual Drift

Developers routinely hardcode unapproved inline styles and hex codes directly in Mendix Atlas SCSS, causing visual fragmentation across app modules.

Manual Re-branding Bottlenecks

Updating brand colors requires manually modifying dozens of independent project repositories, taking days of developer maintenance time.

The Solution Automated Pipeline

Single Source of Truth in Figma

Figma Variables act as the master token source, automatically exporting standardized W3C JSON directly into a central GitHub repository.

Automated Token Engine & Sync

Style Dictionary and GitHub Actions transform raw JSON into read-only SCSS tokens, delivering updates to Mendix apps automatically on launch.

Data Formats & Transformations

Inspect the data structure across each stage of the automated workflow.

  "brand": {

      "$value": "#00893d",

// config.js - Transforms raw JSON tokens to Mendix SCSS
module.exports = {
  source: ['tokens/**/*.json'],
  platforms: {
    scss: {
      transformGroup: 'scss',
      buildPath: 'theme/web/',
      files: [{
        destination: '_brand-tokens.scss',
        format: 'scss/variables'
      }]
    }
  }
};
// Auto-generated by Style Dictionary — READ ONLY
// Imported in Mendix main.scss

// Mendix Atlas Custom Variable Mapping
$navbar-bg: $brand-primary;

05 / Governance & Roadmap

Roles & Deployment Timeline

Cross-functional ownership matrix and implementation phases.

Token Configuration Owner

UI/UX Designer

Responsible for creating and maintaining raw brand variables inside Figma. Pushes tokens using Tokens Studio to trigger the automated build pipeline without needing to write code.

Automation Pipeline Architect

DevOps / CI-CD Engineer

Sets up GitHub Actions and Style Dictionary build scripts. Ensures automated Pull Requests deliver generated read-only SCSS assets directly into the target Mendix repository.

Mendix Integration Specialist

Mendix Developer

Links the incoming _brand-tokens.scss file to Mendix Atlas _custom-variables.scss. Configures design properties to allow drag-and-drop low-code styling.

Stage 1

Token Structuring

Extract existing Mendix brand values and model them into W3C compliant JSON.

Stage 2

Pipeline Configuration

Configure Style Dictionary and GitHub Actions to convert JSON into Mendix SCSS.

Stage 3

Mendix Atlas Mapping

Link the compiled token file with Mendix Atlas UI custom variables.

Stage 4

Live Validation

Modify a color hex code in JSON and verify automatic UI updates in running Mendix app.
